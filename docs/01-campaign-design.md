# 战役设计总纲 — 全面战线：泥泞前线

版本：v0.1 草案
目标体量：20 关 / 9 小时 / 全部新地图 / 线性流程 / 即时演算 CG

> 本作所有国家、组织、人物与事件均为架空创作，不与任何现实国家、军队或个人对应。

---

## 1. 一句话梗概

美国「哨兵特遣队」深入东欧，在斯科拉与北风军事集团的战争全面升级前执行高风险介入行动；随着战局推进，小队发现真正推动战争的不是前线，而是双方内部决定发动第一击的强硬派。

## 2. 阵营与人物

### 2.1 哨兵特遣队（Task Force Sentinel）
- 主角：代号「隼 / FALCON」，小队突击手，玩家扮演。
- 队长：代号「铁锤 / HAMMER」，无线电指挥核心。
- 技术官：代号「织网 / WEBER」，负责无人机、通讯与情报。
- 医疗/机师：代号「织女 / VEGA」，第一关营救对象。
- 友军部队：后续关卡中逐步出现装甲、空中与特种支援。

### 2.2 斯科拉（Skora）
- 领导人：泽布斯基。
- 正规军：装备苏制与西式混装武器，守土作战。
- 内部存在主张先发制人的强硬派。

### 2.3 北风军事集团（Northern Wind Military Group）
- 领导人：普汀。
- 半正规军事集团，拥有装甲、炮兵、防空与雇佣兵体系。
- 高层中有人绕过指挥链推动导弹危机。

## 3. 内容边界

1. 只描写武装人员之间的战斗。
2. 不出现杀害平民、酷刑、处决战俘等可操作内容。
3. 战争代价通过环境与叙事呈现：废墟、撤离车队、广播与信件。
4. 不出现真实国旗、真实部队番号、真实人物肖像。
5. 语言与视觉基调克制，不做廉价煽情。

## 4. 结构：四幕 × 五关

每关目标时长 27 分钟，每幕约 2 小时 15 分，总计约 9 小时。
每关强制要求：新地图、线性推进、至少三段目标链、至少一场大型演出时刻、一次实时 CG 开场或收尾。

## 5. 每关任务模板

每一关必须满足以下节拍，禁止简单守点：

1. 冷开场：环境或事件直接建立情绪。
2. 简报：战术地图 + 小队无线电，不超过 60 秒。
3. 阶段 A：低烈度接触，介绍本关机制。
4. 转折点：目标被破坏或情报被推翻，逼迫玩家移动。
5. 阶段 B：本关核心玩法，敌人组合最强。
6. 高潮演出：载具、爆炸或地形变化。
7. 阶段 C：目标升华，短促高强度。
8. 收尾 CG：埋下下一关钩子。

## 6. 玩家规则

- 战役模式**不提供连杀奖励**：不积累连杀分数，不显示连杀栏，不开放 UAV / 空袭 / 直升机 / 炮艇 / 无畏战士。
- 阵亡 = 从最近检查点重新开始，不设增援票。
- 难度：新兵 / 正规军 / 老兵，影响敌人伤害、反应、资源量。
- 武器：玩家总共携带**两把主武器**；场景武器与敌人掉落武器可按 `F` 替换当前主武器。
- 弹药：敌人死亡掉落弹药，靠近自动拾取；关卡内固定弹药补给点自动补充。
- 投掷物：`Q` 战术投掷物，`G` 杀伤投掷物；两者上限均为 3 个。
- 关卡完成解锁下一关，进度本地保存。
- 情报品：每关 3 个，收集后可解锁额外文本与武器涂装。

## 7. 交付节奏

- 第一阶段只交付「鹰落」。
- 「鹰落」用户验收通过前，不制作任何其他关卡。
- 后续每完成一幕交付一次验收包。
