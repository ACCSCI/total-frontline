# 技术升级方案 — WebGPU-first 3A 观感管线

版本：v0.1 草案
原则：在浏览器预算内追求 3A 完成度，不无脑堆资源。

---

## 1. 现状与结论

现状：

- TypeScript 单文件编译（`outFile`），three.js r128，WebGL2。
- 无 PBR/IBL、无 TAA、无骨骼角色、无 glTF 流式加载、无体积雾。
- 已有：动态分辨率、半浮点 HDR 后处理链、MSAA、软阴影、程序化天空、分块剔除、AI、武器手感和菜单 WebGPU 背景。

结论：保留手感与玩法代码，重构渲染、资产、构建三根柱子。

## 2. 目标架构

```text
Vite + TypeScript ES Modules
├── src/campaign/      战役导演、目标链、检查点、关卡数据
├── src/renderer/      WebGPU-first 渲染器（WebGL2 回退）
├── src/world/         地图流式加载、剔除、光照探针、LOD
├── src/sequencer/     即时演算时间轴
├── src/audio/         Web Audio 混音与动态音乐
├── src/gameplay/      移动、武器、AI、交互
└── assets/missions/   每关独立 glTF/KTX2/音频 manifest
```

## 3. 渲染管线

### 3.1 渲染器
- 现代 three.js WebGPURenderer 为主。
- WebGL2 自动回退；启动时探测，进入低配路径。
- 保留现有渲染器作为「旧死斗模式」过渡，新战役只走新管线。

### 3.2 帧管线
1. 深度前向 / 前向+ 主渲染，PBR + IBL。
2. 级联阴影（CSM）+ 近距离接触阴影。
3. 烘焙光照图 + 反射探针，动态光只负责演出与局部变化。
4. 体积雾、光束、天气（雨/雪/雾/雷）。
5. 后处理：TAA 或 TSR 超分、动态分辨率、SSAO/GTAO、动态模糊、景深、HDR + ACES、色差、胶片颗粒。
6. GPU compute 粒子：爆炸、碎片、弹壳、泥浆、雪花、烟尘。

### 3.3 预算
- 目标：1080p 高配 60fps，低配 30fps。
- 可见三角面 100–180 万。
- Draw call ≤ 3000。
- 显存峰值 ≤ 1.5GB，单关资产压缩后 300–600MB。
- 单关首屏加载 ≤ 8 秒（冷启动），后续关 ≤ 5 秒。

## 4. 资产与流式

- 格式：glTF 2.0 + Draco/meshopt + KTX2/BasisU。
- 工具链：Blender 导出 → 压缩/烘焙 → manifest 校验。
- 每关一份 manifest：地形段、建筑组件、角色、载具、音频、天空参数。
- 运行时按任务触发体积流式加载/卸载；IndexedDB/OPFS 缓存。
- 角色：骨骼蒙皮、动画状态机、程序化命中反应；大特写靠镜头与灯光，不做完整面部动捕。
- 载具：脚本化/轨道式，不做开放驾驶。

## 5. 即时演算 Sequencer

- 时间轴轨道：摄像机、角色、载具、灯光、天气、后期、字幕、音频、触发。
- 全部过场在引擎内实时渲染，不进视频文件。
- 提供导演调试面板：逐帧步进、轨道重播、镜头切换。
- 过场与游玩共用同一地图，无加载缝。

## 6. 玩法系统升级

- 任务导演：触发体积、事件图、目标链、检查点、动态无线电。
- AI：班组协同、破门清房、压制/包抄、狙击、重装、增援导演。
- 玩家动作：滑铲、翻越、侧身、破门、滑索、夜视切换。
- 目标类型：肃清、爆破、交互、护送、抵达、标记打击、限时、装甲目标。

## 7. 音频

- Web Audio 全混音：分层枪声、材质撞击、卷积混响、HRTF。
- 动态音乐按战斗强度切换层。
- 无线电 VO + 字幕，过场与游玩共享音频总线。
- 音效预算：单关常驻声源 ≤ 24，总内存 ≤ 60MB。

## 8. 工程与测试

- 构建：Vite，每关代码与资产独立 chunk。
- 自动化：Puppeteer 灰盒跑关、帧率采样、内存采样、加载计时、崩溃回归。
- 画质档位：低 / 中 / 高 / 超高，启动自动检测。
- 兼容：WebGPU 不可用自动回退 WebGL2；不支持 WebGL2 显示说明页。

## 10. 主要风险与对策

- three.js r128 → WebGPU 迁移量大：保留旧渲染器双轨，新管线先灰盒后替换。
- 浏览器内存与加载：流式 + OPFS + LOD + 按关卡隔离资源。
- 高质量角色动画缺失：骨骼蒙皮 + 程序化动画优先，第一关不承诺面部特写。
- 20 张新地图产能：第一关建立组件库与地图模板后再量产。
