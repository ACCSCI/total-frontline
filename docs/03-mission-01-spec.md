# 第一关垂直切片规格书 — 「鹰落 / NIGHTFALL」

版本：v0.1 草案
定位：整个 20 关战役的质量基准。这一关不过审，后续不量产。

---

## 1. 任务概述

- 代号：鹰落 / NIGHTFALL
- 所属：第一幕「接触」
- 时长：目标 22–27 分钟，熟练重玩 16–18 分钟
- 地图：全新「黑森林河谷」，1.8–2.4 公里线性路径，禁止使用现有仓库区与核弹小镇
- 时间：深夜，暴雨，间歇雷电
- 基调：泥泞、潮湿、孤立、被追击的压迫感

## 2. 叙事

鱼鹰运输机运送「织女 / VEGA」与关键通讯模块穿越斯科拉边境时被肩扛导弹击中，在雷暴中坠入黑森林。玩家从坠机冲击中苏醒，小队失散。玩家必须在北风集团搜索队抵达前找到幸存者，并沿河谷撤离至接应点。

关卡结束钩子：撤离车队离开时，一架不属于任何已知阵营的无人机从云层中锁定车队。

## 3. 玩家状态

- 战役规则：**剧情模式不提供任何连杀奖励**，不积累连杀分数，不显示连杀奖励栏，也不开放 UAV / 空袭 / 直升机 / 炮艇 / 无畏战士。
- 武器槽位：
  - 主武器槽 1：M4 卡宾枪（红点 + 扩容 + 消音 + 垂直握把）起手。
  - 主武器槽 2：消音手枪（P-9）。
  - 数字键 `1` / `2` 切换两把主武器。
- 装备：夜视仪，第一关绑定 NV 教学；后续关保留并升级。
- 生命/受伤：沿用现有街机手感，战役数值只做微调。
- 阵亡：从当前阶段检查点重开，不设增援票。

## 3a. 武器拾取与替换

- 场景中的武器拾取点有高亮轮廓与 HUD 提示：`F 替换 主武器 1/2`。
- 按 `F` 后，当前主武器与地上武器交换；被换下的武器留在地上，可再次换回。
- 敌人死亡后掉落其武器；尸体旁同样显示 `F 拾取`，弹药由玩家靠近自动拾取。
- 第一关武器分布：
  - 坠机点装备箱：KS-12 霰弹枪。
  - 河谷 A 敌方班组：AK-12M 突击步枪。
  - 油料场哨所：SR-7 狙击枪（可选）。
  - 公路桥检查站：P90 单兵自卫武器（可选）。

## 3b. 弹药补给

- 弹药补给点靠近后自动补充当前两把主武器的备用弹。
- 补给点需要短交互或靠近触发，具体以 HUD 提示为准。
- 第一关补给点：
  - 起点坠机残骸 A：小队装备包。
  - 检查点 1 旧伐木道：空投弹药箱。
  - 坠机点主残骸：机舱内弹药箱。
  - 油料场：哨所弹药架。
  - 公路桥检查站：撤离前最后一个弹药箱。

## 3c. 投掷物

- `Q`：战术投掷物 — 闪光弹。
- `G`：杀伤投掷物 — 破片手雷。
- 两种投掷物**上限均为 3 个**，达到上限后拾取不再增加。
- 初始携带：闪光弹 ×1，破片手雷 ×1。
- 获得方式：敌人掉落、弹药补给点补充。
- HUD 显示两个投掷物槽位与数字：`Q 闪光 ×n`、`G 手雷 ×n`；耗尽时数字归零并显示为空。

## 3d. HUD 增量

- 主武器栏显示两个主武器槽位，当前槽位高亮，另一槽位显示武器名。
- 武器拾取提示：屏幕中央偏下 `F 替换 主武器 2 — AK-12M`。
- 弹药拾取提示：`已拾取步枪弹药 +30`，持续 2 秒。
- 投掷物槽位：左下常驻，显示数量，数量为 0 时变暗。
- 剧情模式不显示连杀奖励 HUD，不显示连杀进度条。

## 5. 目标链

1. 苏醒并恢复通讯。
2. 找到失散小队装备点。
3. 抵达主坠机点。
4. 肃清坠机点敌军搜索队。
5. 解救 VEGA，取得通讯模块。
6. 沿河谷撤离，突破三道拦截。
7. 爆破油料场阻断装甲追兵。
8. 抵达公路桥并登上接应车辆。
9. 撤离 CG。

失败条件：玩家死亡（回检查点）、VEGA 死亡（回当前阶段开始）。

## 6. 战斗编排

- 敌人总数：约 26–34 名，含 2 个脚本增援波次。
- 遭遇：9 个战斗节点，全部围绕移动与地形，不允许单点固守超过 45 秒。
- 敌人类型：
  - 步枪手：基础火力与掩体。
  - 霰弹搜索兵：夜间近战压迫。
  - 班组士官：指挥包抄。
  - 装甲车：不可摧毁，沿路推进形成时间压力。
- 节奏曲线：
  - 0–3 分：教学，0 交火。
  - 3–8 分：潜行选择，2–4 敌。
  - 8–15 分：坠机点战斗，8–12 敌。
  - 15–22 分：河谷追击，12–18 敌。
  - 22–27 分：桥头撤离，4–6 敌 + 装甲车压迫。

## 7. 即时演算 CG

### 开场 CG（约 75–90 秒）
1. 云层雷暴，鱼鹰编队低飞。
2. 座舱内无线电，地面导弹告警。
3. 干扰弹发射，第一枚脱靶。
4. 第二枚命中引擎，机身解体。
5. 玩家视角穿过舱门，森林扑面，黑屏。

### 收尾 CG（约 45–60 秒）
1. 车队冲出公路桥，残骸在后视中燃烧。
2. 无线电接入，队长确认任务成功。
3. 镜头升起，云层中出现未知无人机红色光点。
4. 无人机锁定框套住车队，切黑，字幕。

## 8. 音频方向

- 环境：暴雨、雷声、风声、树叶摩擦、泥地脚步。
- 战斗：枪声随距离与遮挡变化，弹着点材质反馈。
- 音乐：低频弦乐铺底；遭遇战进入打击层；追击段加入推进节奏。
- 无线电：全部有字幕，保留无线电滤波处理。

## 9. 美术资产清单（第一关）

- 地形：黑森林河谷，泥地、浅滩、倒木、伐木道。
- 主残骸：鱼鹰机身、旋翼、货舱、散落装备。
- 建筑：废弃林场哨所、油料场、公路桥检查站。
- 道具：弹药箱、沙袋、铁丝网、车辆残骸、照明弹。
- 拾取物：地面武器高亮模型、弹药盒、闪光弹、破片手雷、空投箱。
- 角色：玩家小队、北风搜索兵、VEGA 受伤模型。
- 天气：雨幕、积水反射、闪电、雾层。

## 10. 技术验收标准

- 1080p 高配稳定 60fps；低配 30fps。
- 首屏加载 ≤ 8 秒。
- 全关无破坏性加载停顿。
- 无穿墙、无掉出地图、无 AI 卡死。
- 开场 CG 与收尾 CG 为实时渲染，无视频文件。
- 全程可用键盘鼠标完成，手柄不阻塞发布。
- 所有 HUD 文案与字幕为中文。

## 11. 评审流程

1. 用户试玩「鹰落」灰盒版，确认地图尺度与战斗节奏。
2. 用户试玩「鹰落」美术完成版，确认写实方向与 CG 质感。
3. 用户验收通过后，冻结第一关模板与资产组件库。
4. 未验收通过，只修改第一关，不进入第二关。
